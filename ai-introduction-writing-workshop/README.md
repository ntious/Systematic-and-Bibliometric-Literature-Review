# AI-Assisted Research Introduction Workshop

This repository contains materials for a workshop on writing
scientifically rigorous research introductions using AI as a
critical auditing tool.

*Goal:*
Teach students how to use generative AI to strengthen
argument structure, evidence discipline, and research logic —
not to replace writing.

*Contents:*
- Prompt for AI audit
- Student worksheet
- Example introductions
- Slides from the workshop

*Quick start:*
1. Copy the audit prompt
2. Paste your introduction
3. Run the audit
4. Complete the worksheet
5. Revise intentionally

*Important:*
AI is used as a skeptical reviewer,
not as an authority or ghostwriter.
Students remain responsible for claims and evidence.

This tool supports critical evaluation and revision.
It is not a substitute for original writing or citation.
